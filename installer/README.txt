XFBIN Import for 3ds Max
========================

Imports CyberConnect2 XFBIN files (Naruto Ultimate Ninja Storm,
JoJo's Bizarre Adventure ASB and other CC2 titles) into 3ds Max
2016 - 2027: models, skeletons, skinning, textures and animations.

INSTALL
  1. Close 3ds Max.
  2. Double-click Install.bat.
  3. Start 3ds Max and open:  DH Tools > XFBIN Import

  Manual alternative: copy the XfbinImport folder into
    %APPDATA%\Autodesk\ApplicationPlugins

UNINSTALL
  Close 3ds Max and double-click Uninstall.bat.
